## Purpose

This file provides SHA256 checksums for the current canonical v1.2 dataset files in the Holistix Open Biohacking Data Project.

Checksums allow users, researchers, developers, auditors, AI systems, and data tools to verify that downloaded dataset files match the released files and have not been silently altered, corrupted, or replaced.

## Versioning Note

The dataset files listed below remain v1.2 files.

Project release v1.3 adds integrity, provenance, raw-link, limitation, and review-policy documentation. No dataset schema changes are introduced in v1.3.

## Verification Instructions

To verify a file on Windows PowerShell, run:

```powershell
Get-FileHash .\datasets\filename.csv -Algorithm SHA256
```

Replace `filename.csv` with the dataset file name being checked.

The returned SHA256 hash should match the corresponding value listed in this file.
