# Contributing

Thank you for your interest in the Open Biohacking Data Project.

At this stage, the repository is maintained by Holistix. Public contributions may be reviewed for clarity, formatting, safety framing, and alignment with the educational purpose of the project.

## Contribution Guidelines

Contributions should:

- Use conservative wellness language
- Avoid disease-treatment claims
- Avoid personalized medical advice
- Include clear source or rationale notes when appropriate
- Preserve CSV and JSON formatting
- Follow the existing folder and filename conventions
- Maintain beginner-friendly explanations

## Medical and Safety Framing

This repository is educational only.

Please do not submit content that claims a wellness device diagnoses, treats, cures, or prevents disease.

## Dataset Format

Where possible, dataset updates should include both CSV and JSON versions.

Meaningful changes should also be documented in `VERSION_HISTORY.md`.
