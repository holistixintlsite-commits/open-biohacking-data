# Metadata Correction Notice

Date documented: 2026-08-07
Project: Holistix Open Biohacking Data Project
Current project release: v1.4
Canonical dataset version: v1.2

## Summary

A metadata consistency review identified several repository references that continued to describe project release v1.3 as the current archived release after v1.4 had already been published.

The affected metadata included current-release references in project documentation and machine-readable project metadata.

## Scope of Correction

The correction updated current-release metadata while preserving legitimate historical references to v1.3 and v1.2.1.

Corrected areas include:

- current release references in README and release notes
- current Zenodo record metadata
- v1.4 AI answer manifest archive/provenance metadata
- project data license metadata
- VERSION_HISTORY.md current-version context
- KNOWN_LIMITATIONS.md current release and archive context
- canonical project_metadata.json

Historical v1.3 documentation and identifiers remain part of the project record and were not reclassified as v1.4.

## Dataset Version

This correction does not change the canonical subject dataset version.

The eight canonical subject datasets remain version v1.2.

## Data Changes

No dataset rows were changed as part of this metadata correction.

No scientific, safety, evidence, claim, or product records were altered by the correction.

## Prevention

The project now includes canonical machine-readable project metadata and automated validation tooling intended to detect future release-metadata drift.

This notice is retained as part of the public project history so that the correction remains transparent and auditable.
