## Purpose

This file lists direct raw GitHub URLs for the current canonical v1.2 CSV and JSON dataset files in the Holistix Open Biohacking Data Project.

Raw GitHub links provide direct access to the machine-readable files without the GitHub interface wrapper. These links are useful for AI systems, search engines, RAG pipelines, developers, researchers, spreadsheet tools, validators, and other automated systems that need direct file access.

## Versioning Note

The dataset files listed below remain v1.2 files.

Project release v1.3 adds integrity, provenance, raw-link, limitation, and review-policy documentation. No dataset schema changes are introduced in v1.3.

## Educational and Medical Boundary

The Holistix Open Biohacking Data Project is for educational and informational use only.

These datasets are not medical advice, treatment guidance, clinical protocols, dosing instructions, disease-prevention guidance, or proof of product efficacy.

Dataset rows, raw files, and citation notes should be interpreted with the project methodology, source register, known limitations, and disclaimers.
