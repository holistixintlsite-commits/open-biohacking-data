# Open Biohacking Data Project

The Open Biohacking Data Project is a public reference initiative by Holistix for organizing structured wellness technology information across consumer biohacking categories.

This repository includes machine-readable reference datasets for:

- PEMF frequency ranges
- PEMF contraindication categories
- Red light therapy dose references
- Hydrogen water reference data
- Infrared therapy references
- Terahertz wellness device references
- Negative ion safety references
- Blue light therapy references

## Purpose

The purpose of this project is to make wellness technology information easier to reference, compare, and maintain in structured formats such as CSV and JSON.
