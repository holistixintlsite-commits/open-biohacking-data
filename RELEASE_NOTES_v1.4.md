# Holistix Open Biohacking Data Project v1.4 Release Notes



Release date: July 26, 2026



## Overview



Version 1.4 expands the Holistix Open Biohacking Data Project from a subject-dataset collection into a broader structured product and wellness-technology reference system.



This release adds product intelligence, normalized technology relationships, machine-readable product twins, provenance controls, claim boundaries, safety records, and AI-answer infrastructure.



The eight public subject datasets remain at dataset version v1.2.

## Versioning Note



This is project release v1.4.



The eight subject datasets remain at dataset version v1.2 because their underlying dataset release was not incremented as part of this package.



Individual infrastructure files may retain their own version identifiers where appropriate.



## Evidence and Safety Limitations



The evidence registry is not a fresh systematic literature review. It contains evidence metadata assembled from existing project datasets and source records.



Inclusion does not establish clinical effectiveness, regulatory approval, medical equivalence, or endorsement.



Scientific, medical, safety, and commercial claims should be verified against original sources, current manufacturer documentation, and qualified professional guidance where appropriate.
