## Overview

Version 1.5.0 is an interoperability, reproducibility, and machine-readable packaging release for the Holistix Open Biohacking Data Project.

The eight canonical subject datasets remain at dataset version v1.2.

Project release v1.5.0 supersedes v1.4 as the current published project release.

## Added in v1.5.0

- Frictionless-style Data Package metadata in `datapackage.json`
- machine-readable schemas for the canonical CSV datasets
- human-readable `DATA_DICTIONARY.md`
- Schema.org JSON-LD catalog in `catalog.jsonld`
- RO-Crate 1.2 metadata in `ro-crate-metadata.json`
- deterministic JSONL exports for all eight canonical datasets
- `project_identity.json` separating draft release identity from current public release identity
- generated provenance metadata
- deterministic release-build manifest
- reproducibility and interoperability validation

## Canonical Subject Datasets
