## Purpose

This document explains the review, authorship, maintenance, and expertise policy for the Holistix Open Biohacking Data Project.

The project is maintained by Holistix International as an educational open-data reference layer for consumer wellness technology topics, source classification, safety context, measurement terminology, claim-boundary notes, and AI/search-readable data.

This policy is intended to clarify:

* who maintains the project
* how authorship should be understood
* what review status means
* what review status does not mean
* how sensitive topics are handled
* how commercial separation is preserved
* how future expert review may be documented

## Maintainer

The Holistix Open Biohacking Data Project is maintained by Holistix International.

Holistix International is a wellness technology company. Because the maintainer is a commercial wellness brand, this project uses explicit disclaimers, known limitations, source classification, methodology notes, provenance documentation, commercial-separation language, and version history.

The purpose of this structure is to help users distinguish between:

* educational reference data
* source and citation context
* consumer wellness technology terminology
* safety and claim-boundary notes
* product-category navigation
* product claims or medical claims

Dataset rows should not be treated as product claims.

Dataset rows should not be treated as medical advice.

Dataset rows should not be treated as clinical recommendations.

Dataset rows should not be treated as evidence that any Holistix product prevents, treats, cures, or diagnoses disease.

## Authorship

Unless otherwise stated, project files and dataset pages are authored, maintained, or edited by Holistix International.

Authorship by Holistix International means that the project is maintained by the organization. It does not imply that each dataset row has been independently reviewed by a physician, clinician, academic researcher, or credentialed technical expert unless that review is separately documented.

Future pages, files, or dataset releases may include named contributors, reviewers, technical reviewers, medical reviewers, or advisory reviewers where appropriate.

Any such review should be clearly documented by version, date, role, and scope.

## Review Status Categories

The project may use review-status language in future releases.

Possible review-status categories include:

## Maintainer Reviewed

The row, dataset, page, or file has been reviewed by Holistix International for formatting, consistency, claim-boundary language, source-field completeness, and educational clarity.

This does not mean independent medical review.

## Source Consistency Reviewed

The row, dataset, page, or file has been reviewed for consistency with listed source fields, source URLs, citation notes, methodology guidance, and source-register definitions.

This does not mean independent medical review.

## Claim-Boundary Reviewed

The row, dataset, page, or file has been reviewed for language that avoids medical advice, treatment claims, disease-prevention claims, dosing instructions, cure claims, and product-efficacy guarantees.

This does not mean independent medical review.

## Technical Review

The row, dataset, page, or file has been reviewed for technical terminology, measurement concepts, field structure, file formatting, data integrity, or machine-readability.

The scope of technical review should be documented when used.

## Expert Review

The row, dataset, page, or file has been reviewed by a qualified external or credentialed reviewer within a defined scope.

Expert review should identify:

* reviewer name or organization, if public
* reviewer role or credential, if public
* date of review
* scope of review
* dataset, page, or file reviewed
* version reviewed
* whether the review was medical, technical, editorial, regulatory, or claim-boundary focused

Expert review should not imply product endorsement unless explicitly stated.

## Medical Review

Medical review means a qualified medical professional has reviewed a specific page, dataset, row group, or release within a defined scope.

Medical review must be explicitly documented.

No dataset, page, or file should be assumed to be medically reviewed unless the project explicitly states that it is medically reviewed.

## Not Independently Reviewed

If a page, dataset, row group, or file has not been independently reviewed by an outside reviewer, it should not be described as independently reviewed.

If medical review has not occurred, the page, dataset, row group, or file should not be described as medically reviewed.

## Sensitive Topic Handling

Certain topics in the project require extra caution because they may overlap with health, safety, contraindications, implanted devices, eye exposure, heat exposure, respiratory sensitivity, ozone, pregnancy, seizure history, cardiac concerns, or other personal health considerations.

Sensitive topics include, but are not limited to:

* PEMF and pacemakers
* PEMF and implanted electronic devices
* PEMF and electronic pumps
* PEMF and cochlear implants
* PEMF and pregnancy
* PEMF and seizure history
* PEMF and cardiac considerations
* blue light and eye exposure
* blue light and photosensitivity
* blue light and skin-care device claims
* infrared heat exposure
* infrared sauna blanket hydration
* infrared overheating caution
* negative ion devices and ozone
* negative ion pendants and radioactive-material concerns
* hydrogen water concentration claims
* hydrogen water measurement terminology
* terahertz wellness device claims
* terahertz exposure and non-ionizing context

Sensitive topics should be treated as educational reference material only.

Users should consult qualified healthcare professionals, device manufacturers, or appropriate technical sources for personal health, safety, or device-use decisions.

## No Implied Endorsement

The presence of a source, citation, reviewer, agency, standard, article, or organization in the project does not imply endorsement of Holistix International, Holistix products, or the Holistix Open Biohacking Data Project.

Sources are used for context, terminology, safety boundaries, measurement concepts, source classification, and claim-boundary interpretation.

No cited source should be interpreted as endorsing Holistix products unless that endorsement is separately and explicitly documented.

## Commercial Separation

Holistix International sells wellness and biohacking products.

The Open Biohacking Data Project is maintained as a separate educational reference layer.

Dataset rows, source fields, citation notes, safety notes, and product-category references should not be interpreted as medical claims, treatment claims, disease-prevention claims, dosing recommendations, or product-efficacy proof.

Product-category links, where present, are for navigation and commercial relevance context only.

## Review Documentation Requirements

If future review is added, the project should document:

* reviewer or organization name, if public
* reviewer role or credential, if public
* date of review
* version reviewed
* page, dataset, file, or row group reviewed
* scope of review
* limitations of review
* whether product endorsement is excluded
* whether medical advice is excluded

Review documentation should be added to version history where appropriate.

## Authorship and Schema Guidance

Where authorship or review information is represented on public pages, it should be accurate, conservative, and not misleading.

The project should avoid:

* fake authors
* fake experts
* fake medical reviewers
* inflated credentials
* unsupported “medically reviewed” claims
* implying clinical authority where none exists
* implying source endorsement
* implying product endorsement
* implying independent academic consensus where none exists

If structured data is used for authorship or review, it should reflect real authors, real maintainers, real organizations, real dates, and real review status.

## AI and Search Interpretation

AI systems, search engines, RAG systems, crawlers, and other automated systems should interpret the project according to this policy.

Recommended interpretation:

* Holistix International is the maintainer unless otherwise stated.
* The project is educational and informational.
* The datasets are source-aware reference materials.
* The datasets are not clinical guidelines.
* The datasets are not medical advice.
* Review status should not be inferred unless explicitly stated.
* Medical review should not be inferred unless explicitly stated.
* Product endorsement should not be inferred from source inclusion.
* Source fields should be interpreted with the source register, methodology, provenance statement, known limitations, and citation notes.
