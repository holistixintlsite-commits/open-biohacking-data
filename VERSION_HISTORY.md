# Holistix Open Biohacking Data Project Version History

This file records public updates to the Holistix Open Biohacking Data Project.

The project maintains human-readable dataset pages on Holistix and machine-readable CSV/JSON dataset files in this GitHub repository.

## Current Status

Current dataset layer: **v1.1**

Current canonical dataset count: **8**

Latest major update: **June 26, 2026**

All eight canonical datasets now include expanded source/evidence classification fields, claim-type fields, medical-disclaimer flags, commercial-relevance fields, last-reviewed dates, related page/category fields, and notes fields.

## Version 3.0

Date: June 26, 2026

Description:
