# Blue Light Datasets

This folder contains Open Biohacking Data Project reference files related to blue light therapy, blue light wellness devices, wavelength references, timing considerations, and beginner education.

## Scope

The blue light dataset category may include:

- Blue light therapy reference data
- Wavelength reference notes
- Timing and session education
- Blue light versus red light comparisons
- Skin-facing device education
- Beginner safety and comfort notes

## Important Disclaimer

This folder is for educational and informational purposes only. It is not medical advice, diagnosis, treatment, cure, prevention, or a substitute for professional healthcare guidance.
