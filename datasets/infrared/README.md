# Infrared Datasets

This folder contains Open Biohacking Data Project reference files related to infrared wellness technology, infrared therapy references, infrared heat exposure, sauna blanket education, and beginner safety considerations.

## Scope

The infrared dataset category may include:

- Infrared therapy reference data
- Infrared sauna blanket education
- Heat exposure and session timing notes
- Infrared versus red light comparisons
- Beginner comfort and safety references
- At-home infrared wellness technology notes

## Important Disclaimer

This folder is for educational and informational purposes only. It is not medical advice, diagnosis, treatment, cure, prevention, or a substitute for professional healthcare guidance.
