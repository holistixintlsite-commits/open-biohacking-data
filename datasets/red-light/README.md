# Red Light Datasets

This folder contains Open Biohacking Data Project reference files related to red light therapy, near-infrared light, wavelength ranges, session timing, dose considerations, and beginner education references.

## Scope

The red light dataset category may include:

- Red light therapy dose references
- Wavelength reference ranges
- Beginner timing guidance
- Red light versus near-infrared comparisons
- Device-use education references
- Safety and comfort notes

## Important Disclaimer

This folder is for educational and informational purposes only. It is not medical advice, diagnosis, treatment, cure, prevention, or a substitute for professional healthcare guidance.
