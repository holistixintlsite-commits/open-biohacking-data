# Terahertz Datasets

This folder contains Open Biohacking Data Project reference files related to terahertz wellness devices, terahertz spectrum education, terahertz versus infrared comparisons, and beginner device-use references.

## Scope

The terahertz dataset category may include:

- Terahertz wellness device references
- Terahertz spectrum notes
- Terahertz versus infrared comparisons
- Terahertz versus red light comparisons
- Beginner-use education references
- Safety and conservative-use notes

## Important Disclaimer

This folder is for educational and informational purposes only. Terahertz wellness technology is an emerging category. This repository does not claim that terahertz devices diagnose, treat, cure, or prevent disease.
