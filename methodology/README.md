# Methodology

This folder documents the methodology used for the Open Biohacking Data Project.

The goal of the methodology section is to explain how Holistix organizes, labels, updates, and maintains structured wellness technology reference datasets.

## Methodology Principles

The Open Biohacking Data Project is organized around the following principles:

- Clear category labeling
- Beginner-friendly terminology
- Conservative wellness framing
- Separation of educational references from medical claims
- Machine-readable dataset formats where appropriate
- Version history for meaningful updates
- Human-readable explanations alongside CSV and JSON files

## Dataset Maintenance

Datasets may be updated when new product education, reference categories, safety notes, or public-facing Holistix resources are added.

Meaningful updates should be documented in `VERSION_HISTORY.md`.

## Medical and Safety Framing

The datasets are educational references only. They do not provide medical advice, diagnosis, treatment, cure, or prevention.

Any person with a medical condition, implanted device, pregnancy, prescription medication use, or health concern should consult a qualified healthcare professional before using wellness technology devices.
